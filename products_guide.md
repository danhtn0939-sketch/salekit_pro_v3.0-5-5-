# Shared Inbox

## What is the Shared Inbox?
All messages from every channel (Web, Facebook, Zalo, Telegram, WhatsApp) arrive in one place. Staff reply directly here — no need to open separate apps.

## How to use
1. Go to **Shared Inbox**.
2. Left panel: list of conversations (unread indicator shown). Click to view.
3. Type in the reply box → Send. The message is delivered to the customer's original channel.
4. Optionally link a conversation to a CRM customer profile to preserve history.

## Testing without a real channel
Click **Simulate Tool** → choose a channel → type a message → Send. Creates a simulated message so you can test the full receive-and-reply flow and see real-time notifications — no real account needed.

## Tips
- Every message is tagged with a sentiment label (happy / angry / buying intent / questioning) — use it to prioritize urgent conversations.
- Keyboard shortcut **Ctrl+I** to open the Inbox quickly.
