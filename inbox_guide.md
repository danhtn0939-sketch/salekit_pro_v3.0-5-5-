# Embedding the Chat Widget on Your Website

**Goal:** add the chat widget to your website so customers can message you directly.

## Steps
1. Go to **Embed Widget** page
2. Click **Copy embed code** (a `<script>` snippet)
3. Open your website editor and paste the code just before the `</body>` closing tag
   - **WordPress**: Appearance → Theme Editor → footer.php, or use a plugin like "Insert Headers and Footers"
   - **Shopify / Haravan / Sapo**: find "Custom code" or "Additional scripts" in theme settings
4. Save and reload your website → the chat widget appears in the bottom-right corner

## Customizing the widget appearance
Go to **Bot Preview** to change: bot name, color theme, greeting message, quick-reply buttons. Changes apply to the live widget immediately after saving.

## Notes
- The web widget works independently — you don't need Facebook or Zalo connected
- Messages from the widget go directly to your **Shared Inbox**
- The widget is responsive — works on desktop and mobile browsers
